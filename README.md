# MEU APLICATIVO

QUERO CRIAR UM APP, PARA AJUDAR ACADEMICOS DE ENFERMAGEM.

Objetivo: Agir como um Desenvolvedor Full-Stack Sênior e Designer de UX/UI para converter o conteúdo de um "Caderno de Estágio de Enfermagem," "uma apostila, um textou ou uma mídia de imagem ou vídeo," em um Aplicativo PWA (Progressive Web App) funcional, moderno com todas as possibilidades de desig que o lovable oferece, explorando as melhores e mais eficazes e seja focado em produtividade acadêmica teórica e prática.

Premissas Técnicas:

Acessibilidade Total: O app deve ser acessível sem necessidade de login ou cadastro (armazenamento local via LocalStorage).

Mobile-First: Design otimizado para celulares, pronto para ser convertido em APK via Bubble, Glide, Adalo ou código puro (React/Next.js).

Design System: Estilo "Glassmorphism" ou "Modern Clean", com cores harmoniosas (tons de azul saúde e branco), animações suaves (framer-motion) e navegação intuitiva por abas ou menu hambúrguer.

Estrutura de Conteúdo (Baseada no Caderno de Estágio): Organize o aplicativo nas seguintes seções interativas, garantindo que todos os dados técnicos, fórmulas e valores estejam em tabelas formatadas:

Dashboard (Home): Resumo do estágio, barra de progresso do Ciclo PDCA e atalhos rápidos para procedimentos.

Guia de Procedimentos (Interativo):

Cálculo de Medicamentos: Calculadoras interativas integradas.

Sinais Vitais: Tabela de valores de referência (Normotensão, Taquicardia, etc.).

Exame Físico: Checklist passo a passo (Cefalocaudal).

Módulo PDCA & ODS 3:

Espaço para preenchimento das fases: P (Planejamento), D (Execução), C (Verificação) e A (Ação).

Guia de metas da ODS 3 (Saúde e Bem-Estar) para consulta rápida.

Escalas e Scores: Tabelas interativas para as escalas de Glasgow, Braden e NIHSS (com soma automática de pontos).

Diário de Bordo: Campo para anotações diárias com opção de exportar para PDF formatado em normas ABNT.

Requisitos de Visual e Linguagem:

Linguagem: Use um tom acadêmico, profissional e estritamente humano. Evite termos robóticos ou clichês de IA. O texto deve parecer escrito por um preceptor de enfermagem experiente.

Tabelas: Absolutamente todos os valores numéricos, dosagens e referências devem ser apresentados em tabelas limpas e responsivas.

Imagens 3D: Para cada seção principal, gere ou descreva um espaço para uma ilustração 3D premium (estilo tech-médico) que ajude na imersão visual.

Navegação: Simples, com ícones modernos e transições de página "fade-in".

Resultado Esperado: Forneça a estrutura de pastas, o código-base (HTML/Tailwind/JS ou lógica No-Code) e o roteiro de design para que o app seja uma ferramenta indispensável e encantadora para o estudante.
