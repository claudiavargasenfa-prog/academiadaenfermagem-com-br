## Problema

O link que você está acessando no celular (provavelmente `academiadeenfermagem-app.lovable.app`) é a versão **publicada**. As alterações que fizemos (banner da loja, página de Prescrição, etc.) só ficam no **preview** até que o app seja republicado.

No Lovable, mudanças de frontend **não vão automaticamente** para o link público — é preciso clicar em **Publish → Update** (ou eu posso disparar a republicação por você).

## O que fazer

1. **Republicar o app** para que o link público (`academiadeenfermagem-app.lovable.app`) receba:
   - Banner curto da loja
   - Página `/prescricao` nova
   - Remoção de fontes/referências do admin e da loja
2. Depois disso, no celular:
   - Abrir o link
   - **Puxar a tela para baixo** para forçar atualização (ou fechar e reabrir a aba) — o navegador às vezes guarda a versão antiga em cache
3. Se ainda assim aparecer o banner longo, abrir em **aba anônima** para confirmar que é cache do celular
